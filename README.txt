CHARLS VALENCIA — PORTFOLIO WEBSITE

Open index.html in a browser to preview.

Pages: index.html, about.html, services.html, projects.html, contact.html

BEFORE PUBLISHING:
1. In script.js replace YOUR_EMAIL@example.com with your real email address.
2. In contact.html add your professional email and LinkedIn URL.
3. In projects.html replace placeholder project category previews with approved actual work.
4. Review and confirm the experience and service descriptions.
5. Optional: add your resume, profile photo, and real project screenshots.

To publish: upload the site files (not make.py) to a static hosting service such as Netlify, GitHub Pages, or Cloudflare Pages. No backend is required. The contact form uses mailto, not a server.
