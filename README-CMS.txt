CHARLS VALENCIA PORTFOLIO — EDITABLE CMS EDITION

This website is ready for a Git-backed content dashboard using Pages CMS.

SETUP (one time):
1. Create a free GitHub repository and upload ALL files from this folder to its root, including the hidden .pages.yml file.
2. Sign in at https://pagescms.org with GitHub and authorize access to your repository.
3. Open the repository in Pages CMS, then open Portfolio Content. Edit fields and save.
4. Deploy the SAME GitHub repository using Netlify (Import from Git) or another static host. Set publish directory to repository root; no build command is needed.
5. Every CMS save commits changes to GitHub. Your host should automatically redeploy after each commit. Your public URL remains unchanged.

IMPORTANT:
- The admin dashboard is hosted by Pages CMS; it is NOT a /admin page on your website.
- You must complete the GitHub/CMS/hosting connections yourself; they are not configured by downloading this ZIP.
- GitHub repository access controls who can edit; do not share your GitHub login.
- Contact email is intentionally blank. Set it in Pages CMS before using the inquiry form.
- Replace example project descriptions with approved real work. Never publish confidential client files.
- Preview locally using a local web server (e.g. python3 -m http.server 8000); direct file:// viewing may block loading JSON.
- Project image uploads use the assets folder, which Pages CMS will manage.
